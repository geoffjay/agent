# Configuration Examples

This directory contains example configuration files for the agent application in different formats.

## Available Examples

- [Agentfile.yml](./Agentfile.yml) - YAML format (recommended)
- [Agentfile.json](./Agentfile.json) - JSON format
- [Agentfile.toml](./Agentfile.toml) - TOML format

## Usage

To use one of these examples:

1. Copy the example file to your project's root directory:
   ```bash
   cp config/examples/Agentfile.yml /path/to/your/project/
   ```

2. Edit the configuration file to match your requirements.

3. Run your application from the project directory where the configuration file is located.

For more information on available configuration options and environment variable overrides, see the [Configuration Guide](../README.md).
